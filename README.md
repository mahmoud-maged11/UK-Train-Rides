# UK-Train-Rides Analysis

This project analyzes UK train rides through four phases: **Preprocessing**, **Analysis**, **Forecasting**, and **Dashboarding**. Python is used for data preparation, exploration, and forecasting, while Power BI delivers an interactive dashboard with key insights.

## 1. Preprocessing
- Load raw datasets (journey times, delays, statuses). 
- Clean missing or inconsistent values and unify time formats. 
- Create calculated fields such as trip duration and delay minutes.

## 2. Analysis
- Explore patterns in train performance and delays. 
- Identify trends, peak times, and anomalies using Python visualizations. 
- Extract insights on operational efficiency and rider behavior.

## 3. Forecasting
- Build predictive models to forecast demand or delays. 
- Evaluate model performance with metrics like MAE and RMSE. 
- Produce future predictions to support planning and decision-making.

## 4. Dashboard
- Develop an interactive Power BI dashboard to visualize KPIs, delay metrics, journey distributions, and forecast outputs. 
- Provide clear, actionable visuals for stakeholders.

## Technologies
- **Python**: pandas, numpy, matplotlib, scikit-learn 
- **Power BI** 
- **Jupyter Notebook**
